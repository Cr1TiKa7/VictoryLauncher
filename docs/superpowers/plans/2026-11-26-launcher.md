# AnyXboxX Launcher Implementation Plan

> Executed natively in one session (superpowers:executing-plans). No commits: the user has not asked for any.

**Goal:** A WPF launcher that keeps AnyXboxX on the newest commit, builds it, warms the shader cache with progress and starts the game.

**Architecture:** All logic in a class library with xUnit tests; the WPF project is a thin window over it. Child processes (git, cargo, victory) run through one runner that reads both pipes asynchronously.

**Tech Stack:** .NET 10, WPF, xUnit.

**Spec:** `../specs/2026-11-26-launcher-design.md`

## Global Constraints
- UI texts German, code identifiers English.
- Defaults: repo `G:\AnyXboxX`, game `G:\DevElop`, cache `G:\victory-data\cache-anyxboxx`, `VICTORY_CARD_BUFFERS_MB=1024`, first warm total 25758 (labelled estimate).
- Never write into the game folder. Never overwrite local changes in the repo.

## Review Focus
1. Untracked files in the checkout must not block updates; tracked changes must not be overwritten (Task 2).
2. Tens of thousands of output lines must neither deadlock the child nor freeze the window (Task 3, real warm run).
3. A cache folder inside the repo or the game folder is refused with a readable message (Task 1).
4. A stray `VICTORY_*` user variable must not reach the child; warm and run get the same environment (Task 1).
5. Closing the window while the game or a build runs must not kill it silently (Task 4).

## Files
- `src/AnyXboxLauncher.Core/`: `Tuning.cs`, `LaunchSetup.cs` (settings, path checks, environment, warm inputs), `WarmProgress.cs`, `ProcessRunner.cs`, `RepoUpdater.cs`
- `src/AnyXboxLauncher/`: `MainWindow.xaml(.cs)`
- `tests/AnyXboxLauncher.Tests/`: one test file per Core file, `fixtures/lancer_victory.ps1`

### Task 1: Tuning table, environment, path checks, warm inputs
**Produces:**
- `Tuning.Parse(string script) -> IReadOnlyDictionary<string,string>`: entries of the `$tuned` table plus column 0 `$env:VICTORY_X = 'literal'` lines. Throws `InvalidDataException` when the table is missing or empty.
- `record LauncherSettings(string RepoDir, string GameDir, string CacheDir, string? LastWarmCommit, string? LastWarmCacheDir, int? LastWarmTotal)` with `Load(path)` / `Save(path)`; a missing or broken file gives the defaults.
- `PathCheck.Validate(LauncherSettings) -> string?` (German message or null): repo has `third_party\victory\Cargo.toml` and `tools\lancer_victory.ps1`; game has `game_scarlett_master.exe`; cache is not inside repo or game.
- `LaunchEnvironment.Apply(IDictionary<string,string?> env, IReadOnlyDictionary<string,string> tuned, string gameDir, string cacheDir)`: removes every `VICTORY_*`, then sets tuned, `VICTORY_CARD_BUFFERS_MB=1024`, `VICTORY_GAME_DIR`, `VICTORY_CACHE_DIR`.
- `WarmInputs.Collect(string gameDir) -> string[]`: `*.rpf` sorted by name, then game exe, `XboxBvhBuilder.dll`, `amd_fidelityfx_upscaler_xbox.dll` where present.

- [ ] Tests against a copy of the current script: `CARD_WINDOWS_MB == "1536"`, `PIPELINE_WAIT_MS == "2500"`, `COPY_COALESCE == "256"`, `DISCORD == "0"`, `OCEAN_READBACK == "1"`, no `VICTORY_AUTO_A`, `LIST_POOL_MB == "512"` (not the Quality value 256); empty script throws.
- [ ] Tests: stray `VICTORY_FOO` removed, override applied; path checks for cache inside repo, inside game, missing exe; input order.
- [ ] Implement, `dotnet test` green.

### Task 2: RepoUpdater
**Produces:** `RepoUpdater(string git, string repoDir).CheckAndPullAsync(Action<string> log, CancellationToken) -> Task<UpdateResult>` with `record UpdateResult(UpdateState State, string Head, IReadOnlyList<string> NewCommits, string? Message)`, `enum UpdateState { UpToDate, Updated, CheckFailed, Blocked }`. Flow: `fetch`, count `HEAD..@{u}`, if tracked changes (`status --porcelain --untracked-files=no`) and behind: Blocked; else `merge --ff-only @{u}`, failure: Blocked.

- [ ] Tests with real temporary repos (bare origin, clone, push a new commit): UpToDate, Updated (HEAD equals origin), tracked change gives Blocked and keeps the file, untracked file does not block, unreachable origin gives CheckFailed.
- [ ] Implement, green.

### Task 3: ProcessRunner and WarmProgress
**Produces:**
- `ProcessRunner.RunAsync(ProcessStartInfo, Action<string> onLine, CancellationToken) -> Task<int>`: redirects both pipes with `BeginOutputReadLine`/`BeginErrorReadLine`; cancel does `Kill(entireProcessTree: true)` and throws `OperationCanceledException`.
- `Tools.Find(string name) -> string?`: `%USERPROFILE%\.cargo\bin\<name>.exe`, then `PATH`.
- `WarmProgress(int total)` with thread safe `Feed(string line)`, `int Count` (max of counted `shader translated` lines and the last `N shaders` report), `double Percent` (capped at 99 until the result line), `string? ResultLine`, `int? ResultTotal` (translated plus refused).

- [ ] Tests: `"    63 s  2000 shaders"` gives 2000; `shader translated` lines count; max of both; result line `warm         25753 translated, 5 refused; 2729 compute pipelines, 0 refused; 410 s` gives total 25758 and 100 %; runner test with a child writing 20000 lines to both pipes finishes; cancel kills it.
- [ ] Implement, green.

### Task 4: Window
Paths with browse buttons, version line with "Prüfen", warmup button with bar and counter and cancel, "Spiel starten", log tail. Behaviour per spec, plus:
- Update check = `RepoUpdater` then `cargo build --release -p victory --manifest-path <repo>\third_party\victory\Cargo.toml`; runs at window load and before warmup and start; skipped with a message while `victory.exe` runs. If it fails and an exe exists, ask whether to continue with it.
- Lines go to `logs\*.log`; the UI is refreshed by a 250 ms `DispatcherTimer` only.
- Working directory of children is the launcher folder.
- Cancelled warmup says it has to be redone. Warm hint when `LastWarmCommit != HEAD` or cache folder differs.
- Close: during warmup ask, then kill; during game or update refuse with a message.

- [ ] Implement, `dotnet build` without warnings, `dotnet publish` to `app\`.
