# Tastenbelegung im Launcher: Umsetzungsplan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Der Launcher zeigt die Tastenbelegung des gewählten Forks mit den Beschriftungen der eigenen Tastatur.

**Architecture:** Die Tabellen und Hinweise liegen als reine Funktionen in `VictoryLauncher.Core`. Die einzige
Windows-Abfrage (Taste an einer Position) ist austauschbar, damit Tests nicht vom Tastaturlayout abhängen. Das Fenster
zeigt nur an.

**Tech Stack:** .NET 10, WPF, xUnit 2.9.

**Spec:** `docs/superpowers/specs/2026-11-26-controls-design.md`

## Global Constraints

- Oberfläche und README auf Englisch.
- Der Spielordner wird nicht angefasst.
- Kein Commit ohne Auftrag.

## Review Focus

- Deutsche Tastatur: AnyXboxX zeigt LT als `Y`, alle anderen als `Z`.
- Layout, bei dem an der Position kein Buchstabe liegt: das Zeichen der Taste, nicht ein Steuerzeichen.
- Windows kennt die Position nicht (Antwort 0): der QWERTY-Buchstabe.
- Knopf während Warmup und Spiel: bedienbar. Bei `Own Git URL …`: gesperrt.
- Eigene Git-URL: Hinweis, dass die Tabelle nicht geprüft ist.
